# 5. 工具：HG / 过渡 / 去闪烁 / XMP

[English](../en/05-tools.md) · [文档首页](README.md)

「工具」页包含四个面向整段序列的操作：

1. **Holy Grail 向导**：补偿日转夜拍摄中的相机曝光跳变；
2. **关键帧自动过渡**：在关键帧之间插值全部创意参数；
3. **视觉去闪烁**：测量调色后亮度并写入逐帧 EV 修正；
4. **导出 XMP 边车**：把当前调整写成 Camera Raw 兼容的边车文件。

![工具页](../assets/screenshots/tools.png)

## 5.1 Holy Grail 向导

![Holy Grail 卡片](../assets/screenshots/holy-grail.png)

### 作用

日转夜拍摄时，相机会不断改变快门、光圈或 ISO，导致画面亮度出现台阶。Holy Grail 根据 EXIF 曝光值与画面亮度构造一条补偿曲线，把这些台阶抵消，同时保留真实的日落变暗趋势。

### 参数

| 参数 | 范围 | 步进 | 默认 | 作用 |
|------|------|------|------|------|
| 偏移 | −5.00 … +5.00 | 0.05 | 0 | 整体抬高或压低补偿曲线 |
| 拉伸 | −1.50 … +1.50 | 0.02 | 0 | 放大 / 缩小相机曝光趋势的补偿强度 |
| 旋转 | −4.00 … +4.00 | 0.04 | 0 | 让补偿曲线随时间线性倾斜 |
| 初始平滑 | 0.00 … 1.00 | 0.01 | 0.50 | 对原始曝光曲线做 LOESS 平滑的强度 |

### 计算模型

对每帧 `i`，设归一化时间 `t = i / (n−1)`，相机曝光趋势 `trend` 为去均值后的 EV 序列：

```text
ramp        = (t − 0.5) × 旋转 + 偏移
compensation = −trend × (1 + 拉伸) + ramp
exposure     = LOESS(compensation, 初始平滑)   // 夹紧到 ±5 EV
```

白平衡部分：

```text
jump        = wb − LOESS(wb, 0.45)
temperature = −jump × (0.35 + 拉伸 × 0.15) + (t − 0.5) × 旋转 × 2
```

- `wb` 是灰世界白平衡代理值；
- 平滑后的慢速色温漂移被保留，快速跳变被抵消；
- `tint` 固定为 0。

### 自动优化

点击「自动优化」会执行两阶段网格搜索：

| 阶段 | 范围 | 步长 | 评估次数 |
|------|------|------|----------|
| 拉伸 | −1.50 … +1.50 | 0.02 | 151 |
| 旋转 | −4.00 … +4.00 | 0.04 | 201 |
| 合计 | | | 352 |

评分函数同时考虑：

- 调整后亮度曲线的粗糙度（二阶差分绝对值均值）；
- 曝光修正绝对值的均值（惩罚过大的补偿）；
- 色温修正绝对值的均值（较小权重）。

序列超过 600 帧时，优化会在等间隔子采样上搜索，找到参数后再应用到完整序列，以保持按钮响应。

> 自动优化只改变「拉伸」和「旋转」，不会改动「偏移」与「初始平滑」。优化结果会四舍五入到 0.01 后写回参数。

### 操作步骤

1. 确认序列已导入且 EXIF 可用（没有 EXIF 时会回退到亮度）；
2. 可选：点击「标记首尾关键帧」，为后续过渡准备锚点；
3. 点击「自动优化」，等待状态栏显示「自动优化完成」；
4. 检查曲线与预览，必要时手动微调四个参数；
5. 点击「应用」，把补偿写入每帧的 `exposure` / `temperature` / `tint`；
6. 若结果不理想，点击「重置」把四个参数恢复默认（偏移 0、拉伸 0、旋转 0、初始平滑 0.5），再重新应用。

### 注意

- 「应用」会**覆盖**当前所有帧的曝光、色温、色调，包括此前的创意调整；
- 关键帧标记不会被清除，但关键帧上的曝光值也会被覆盖；
- 自动优化是同步计算，序列很长时界面会短暂无响应；
- HG 结果写入的是普通调整值，之后仍可手动修改并重新过渡。

## 5.2 关键帧自动过渡

![自动过渡卡片](../assets/screenshots/transition.png)

### 作用

把关键帧上的调整值插值到中间的每一帧，形成平滑的曝光与色彩过渡。

### 模式

| 模式 | 公式 | 特点 |
|------|------|------|
| 平滑（默认） | `u²(3 − 2u)` | 在关键帧处斜率为 0，起止柔和 |
| 线性 | `u` | 匀速变化，转折处有折角 |

其中 `u = (i − a) / (b − a)`，`a`、`b` 为相邻关键帧下标。

### 参与插值的参数

全部 10 个创意列：

```text
曝光、色温、色调、对比度、高光、阴影、白色、黑色、饱和度、自然饱和度
```

**不参与**：去闪烁修正 `deflicker`。它是逐帧测量值，必须保持独立。

### 边界行为

| 关键帧数量 | 行为 |
|------------|------|
| 0 | 提示「至少需要两个关键帧」，不做修改 |
| 1 | 把该关键帧的值复制到所有帧 |
| ≥ 2 | 相邻关键帧之间插值；首关键帧之前、末关键帧之后保持边界值 |

关键帧自身的值不会被覆盖。

### 操作步骤

1. 至少标记两个关键帧；
2. 选择「平滑」或「线性」；
3. 点击「应用自动过渡」；
4. 状态栏显示「自动过渡完成（平滑 / 线性）」；
5. 用曲线检查过渡是否连续。

> 过渡会覆盖中间帧原有的手动调整。若中间帧需要独立风格，请在该帧重新调整并标记为关键帧后再过渡。

## 5.3 视觉去闪烁

![视觉去闪烁卡片](../assets/screenshots/deflicker.png)

### 作用

测量**当前调色后**的逐帧亮度，估计高频闪烁分量，并把修正写回每帧的 `deflicker` EV。它不会改变创意曝光，而是叠加在曝光之上。

### 参数

| 参数 | 范围 | 默认 | 作用 |
|------|------|------|------|
| 平滑度 | 0.02 … 1.00 | 0.50 | LOESS 窗口占比；越大越平滑，越小越贴近原始曲线 |
| 精度 | 粗略 / 标准 / 精细 | 标准 | 判定为噪声的亮度差阈值 |
| 多遍 | 1 … 4 | 2 | 重复平滑与修正的次数 |
| 恒定模式 | 开 / 关 | 关 | 开启后把所有帧拉向全序列平均亮度 |

精度对应的相对亮度阈值：

| 精度 | epsilon | 含义 |
|------|---------|------|
| 粗略 | 0.005 | 只修正明显闪烁 |
| 标准 | 0.002 | 常规素材推荐 |
| 精细 | 0.0005 | 保留更多细节，可能引入轻微漂移 |

### 算法

1. 对每帧计算 `log2(luma × 2^base_ev)`，得到对数亮度；
2. 用 LOESS（窗口 = 平滑度）拟合慢速趋势；
3. `delta = target − current`，小于 epsilon 的差值置零；
4. 差值夹紧到 ±2 EV，累加到修正并更新当前曲线；
5. 若开启多遍，重复步骤 2–4；没有变化时提前结束；
6. 恒定模式把 target 设为全序列平均对数亮度，而不是 LOESS 曲线。

修正结果写入 `adj.deflicker`，总 EV 变为 `exposure + deflicker`。

### 闪烁指数

卡片底部显示 `闪烁指数 before → after`。指数定义为：

```text
去除 0.35 窗口 LOESS 趋势后的残差标准差 × 100
```

数值越小越稳定。它用于比较修正前后，不参与渲染。

### 操作步骤

1. 先完成 HG 与关键帧过渡；
2. 选择平滑度、精度与遍数；
3. 点击「分析并去闪烁」，等待后台线程完成；
4. 查看闪烁指数与预览；
5. 不满意可调整参数后重跑，或点击「清除」把所有 `deflicker` 归零。

### 注意

- 去闪烁基于**缩略图/预览**的视觉曲线，不是全分辨率分析；
- 它测量的是调色后的亮度，因此应在创意调色之后运行；
- 每次运行都会重新计算并覆盖旧的 `deflicker`；
- 「清除」不会影响创意曝光与关键帧；
- 多遍会增加耗时，通常 2 遍足够。

## 5.4 导出 XMP 边车

![XMP 导出提示](../assets/screenshots/xmp-export.png)

### 行为

- 为每个未跳过的图像写一个同名 `.xmp` 文件；
- 已存在的 XMP 会被**就地更新**：只改写 `crs:*` 与本程序的 `lrt:*` 字段，保留其他软件写入的标签、评级、版权等元数据；
- 写入成功后状态栏显示「已写入 N 个 XMP 边车文件」，并弹出「导出了 N 个 XMP」提示；
- 渲染时若勾选「写入 XMP 边车」，会在渲染前自动执行同一操作。

### 字段

| 字段 | 值 |
|------|-----|
| `crs:Version` | `15.0` |
| `crs:ProcessVersion` | `15.4` |
| `crs:HasSettings` | `true` |
| `crs:WhiteBalance` | 非零色温/色调时为 `Custom`，否则 `As Shot` |
| `crs:Temperature` | `5500 + 色温 × 20`（仅 Custom） |
| `crs:Tint` | 色调（仅 Custom） |
| `crs:Exposure2012` | 总 EV（曝光 + 去闪烁） |
| `crs:Contrast2012` 等 | 对应调整值 |
| `crs:HasCrop` | `false` |
| `lrt:Keyframe` | `True` / `False` |
| `lrt:Deflicker` | 逐帧去闪烁 EV |
| `lrt:Exposure2012` | 不含去闪烁的创意曝光 |

### 注意

- XMP 与原始照片同名，放在同一目录；
- 文件名大小写与扩展名不影响边车命名，统一使用 `.xmp`；
- 如果目标目录不可写，导出会失败并在状态栏提示错误；
- XMP 只记录调整，不包含图像像素；需要成片请使用渲染。
