# 用户手册

## 1. 安装与启动

### 预构建版本

`dist/` 目录包含：

```text
dist/
  timelapse_assistant.exe   桌面程序
  tlcore.exe                无界面 CLI
  components/               FFmpeg 组件（首次运行生成）
```

双击 `timelapse_assistant.exe` 启动。也可以在命令行传入序列目录：

```bash
timelapse_assistant.exe "D:/photos/my-timelapse"
```

启动参数：

```text
<folder>           直接载入序列目录
--tab adjust|tools|render|settings   打开指定页签
--frame N          初始定位到第 N 帧（从 1 开始）
```

### 首次运行与 FFmpeg

程序不需要预装 FFmpeg。首次运行会：

1. 在 `PATH` 和常见安装目录中查找系统 FFmpeg；
2. 找到时复制到 `components/ffmpeg/<版本>/` 并选中；
3. 未找到时从镜像安装 FFmpeg 4.1.0；
4. 镜像失败时尝试官方最新版。

组件管理入口：顶部“设置”按钮。

可执行的操作：

- 快速安装（镜像）
- 下载最新版
- 从 ZIP/TGZ 安装
- 导入系统 FFmpeg
- 在已安装版本之间切换
- 卸载某个版本
- 回退到系统 FFmpeg
- 打开组件目录

组件目录默认在程序旁边；如果程序目录只读，会回退到：

```text
%LOCALAPPDATA%\TimelapseAssistant\components
```

## 2. 界面说明

### 顶部栏

- 打开文件夹、保存、重新扫描
- 工作流状态：初始化、关键帧、HG 向导、自动过渡、去闪烁、渲染
- 当前 FFmpeg 版本
- 渲染视频
- 设置

### 左侧序列列表

显示缩略图、文件名、曝光修正、亮度、错误标记和关键帧标记。点击任意行切换当前帧。

### 中央预览

- 顶部叠加显示帧号和文件名
- 关键帧会显示“关键帧”标记
- 下方是亮度/曝光曲线、关键帧刻度和当前播放头
- 底部按钮：上一帧、播放/暂停、下一帧、标记关键帧、上一/下一关键帧

播放时预览使用缓存缩略图，保证流畅；暂停后自动恢复高清预览。

### 右侧面板

- **调整**：单帧曝光、色温、色调、影调、色彩、序列概览
- **工具**：Holy Grail 向导、关键帧自动过渡、视觉去闪烁、XMP 导出
- **渲染**：输出格式、画质与动效、高级导出、输出路径
- **设置**：FFmpeg 组件管理

## 3. 导入序列

点击“打开文件夹”，选择包含照片的目录。

- 支持的扩展名：jpg、jpeg、png、tif、tiff、dng、cr2、cr3、nef、arw、raf、orf、rw2、srw、pef
- 默认按文件名自然排序（数字按数值排序）
- 解析 EXIF：拍摄时间、ISO、快门、光圈、曝光补偿
- 为每张图生成 640px 缩略图并测量亮度、白平衡
- 项目文件保存在 `.lrtassist/project.json`
- 缩略图保存在 `.lrtassist/thumbs/`

再次打开同一目录会自动合并已有调整和关键帧；文件未变化时复用缩略图。

## 4. 单帧调整

调整页对当前选中帧生效：

- 曝光：-5 到 +5 EV
- 色温、色调：-100 到 +100
- 对比度、高光、阴影、白色、黑色：-100 到 +100
- 饱和度、自然饱和度：-100 到 +100

操作方式：

- 点击滑轨分段直接设值
- 使用 `−` / `+` 微调
- “重置”恢复该帧的全部调整
- “自动关键帧”开启时，修改任意滑块会把当前帧标记为关键帧

## 5. 关键帧与自动过渡

### 标记关键帧

- 预览下方“标记关键帧”
- 再点一次取消
- “上一关键帧 / 下一关键帧”快速跳转
- 工具页“标记首尾关键帧”

### 自动过渡

1. 至少标记两个关键帧
2. 在关键帧上设置曝光、色温、对比度等参数
3. 工具页选择“平滑”或“线性”
4. 点击“应用自动过渡”

程序会在关键帧之间插值所有创意调整列，保留关键帧原值；去闪烁修正不参与插值。

## 6. Holy Grail 向导

用于日转夜/夜转日拍摄，补偿相机在拍摄过程中做出的曝光调整。

参数：

- **偏移**：整体提亮或压暗
- **拉伸**：增强或减弱相机曝光曲线的补偿幅度
- **旋转**：增加线性亮度斜坡，用于创意过渡
- **初始平滑**：对原始曝光曲线做 LOESS 平滑

操作：

1. 点击“自动优化”，程序会在拉伸和旋转范围内搜索较优组合
2. 或手动调整参数后点击“应用”
3. 应用后会自动写入所有帧的曝光/色温/色调曲线
4. 标记首尾关键帧，调整创意参数，再执行自动过渡

## 7. 视觉去闪烁

用于消除拍摄过程中由快门、光圈、光源或后期导致的亮度闪烁。

参数：

- **平滑度**：LOESS 采样窗口比例，越大越平滑
- **精度**：粗略 / 标准 / 精细，决定最小修正阈值
- **多遍**：1–4 遍，逐次修正残余闪烁
- **恒定模式**：把整段亮度拉到同一均值，适合恒定光照场景

点击“分析并去闪烁”后，程序会：

1. 用当前调整渲染缩略图
2. 计算每帧亮度
3. 对亮度曲线做 LOESS 平滑
4. 把差值写回曝光修正（EV）
5. 刷新预览和曲线

“清除”会把所有帧的去闪烁修正归零。

## 8. XMP 边车

工具页“导出 XMP”会把每张图的调整写入同名 `.xmp` 文件：

- `crs:Exposure2012` 包含曝光与去闪烁修正
- 色温/色调、对比度、高光、阴影、黑白场、饱和度等
- 工作流标记用于本程序再次载入
- 已有 XMP 中的无关字段会被保留

渲染时默认也会写 XMP，可在渲染设置中关闭。

## 9. 渲染

### 基础设置

- 分辨率：1080p / 4K / 竖屏
- 帧率：24 / 25 / 30 / 60
- 编码：H.264 / H.265 / ProRes

### 高级导出

开启“高级导出设置”后：

- **码率模式**
  - 质量优先（CRF）：使用质量滑块，恒定质量
  - 目标码率（VBR）：2–100 Mbps
- **编码预设**：快速 / 均衡 / 高质量
- **运动模糊**：按邻帧加权混合
- **锐化**：0–2.0
- **写入 XMP 边车**
- **保留输出帧**

ProRes 使用 profile 3 固定质量，码率与 CRF 设置不生效。

目标码率使用 `-b:v`、`-maxrate`、`-bufsize` 的 VBR 模式；简单画面实际码率可能低于目标值。

### 输出

- “输出目录”选择目标目录
- “打开位置”定位上次输出
- “开始渲染”启动后台渲染，状态栏显示进度
- 渲染中可取消

输出默认是 MP4 或 MOV；ProRes 输出 MOV。

## 10. 保存与项目文件

- 修改调整、关键帧、设置后自动保存
- 顶部“保存”立即写入
- 关闭窗口时如有未保存修改也会保存

项目文件：

```text
<序列目录>/.lrtassist/project.json
```

包含：

- 每帧的调整与关键帧
- 序列设置（去闪烁、HG、过渡）
- 渲染设置（分辨率、码率、编码、输出路径）
- 工作流状态
- 缩略图索引

## 11. 批处理 CLI

```bash
tlcore analyze "D:/photos/seq"
tlcore hg "D:/photos/seq"
tlcore deflicker "D:/photos/seq"
tlcore render "D:/photos/seq" "D:/out/seq.mp4"
```

完整命令见项目 README。

## 12. 常见问题

### 没有画面预览

- 检查文件是否能被解码；左侧对应行会显示 `!`
- RAW 特殊压缩会回退到内嵌预览
- 确认文件未被其他程序独占

### 找不到 FFmpeg

- 打开“设置”查看当前组件状态
- 点击“快速安装（镜像）”或“导入系统 FFmpeg”
- 也可以从官方源下载最新版

### 渲染按钮不可用或失败

- 确认设置页显示 FFmpeg 已就绪
- 检查输出目录是否可写
- 尝试改用系统 FFmpeg 或另一个内置版本

### 目标码率与文件大小不符

- 目标码率是 VBR 平均值，简单画面会低于目标
- 需要稳定质量时使用 CRF

### 渲染速度慢

- 4K/ProRes、运动模糊和高质量预设都会增加耗时
- 关闭“保留输出帧”可减少磁盘写入
- 关闭其他占用 CPU/磁盘的程序

### 项目副本迁移

复制整个序列目录（包含 `.lrtassist`）即可保留调整和关键帧。仅复制图片不会带走项目状态。
