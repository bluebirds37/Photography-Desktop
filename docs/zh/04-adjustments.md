# 4. 单帧调整

[English](../en/04-adjustments.md) · [文档首页](README.md)

「调整」页对**当前帧**做曝光、白平衡与影调调整。每帧拥有独立的 10 个参数，另有一个由去闪烁引擎写入的 EV 修正。关键帧之间可以通过自动过渡把这些参数连成平滑曲线。

![调整面板](../assets/screenshots/adjust.png)

## 4.1 参数总表

| 参数 | 范围 | 步进 | 默认 | 说明 |
|------|------|------|------|------|
| 曝光 | −5.00 … +5.00 EV | 0.05 | 0 | 创意曝光补偿 |
| 色温 | −100 … +100 | 1 | 0 | 相对白平衡偏移，暖 / 冷 |
| 色调 | −100 … +100 | 1 | 0 | 绿 / 品红偏移 |
| 对比度 | −100 … +100 | 1 | 0 | 影调对比 |
| 高光 | −100 … +100 | 1 | 0 | 高光区域 |
| 阴影 | −100 … +100 | 1 | 0 | 阴影区域 |
| 白色 | −100 … +100 | 1 | 0 | 白场 |
| 黑色 | −100 … +100 | 1 | 0 | 黑场 |
| 饱和度 | −100 … +100 | 1 | 0 | 全局饱和度 |
| 自然饱和度 | −100 … +100 | 1 | 0 | 偏重低饱和区域 |
| 去闪烁 | 由工具页写入 | — | 0 | 只读的逐帧 EV 修正，不在本页手动编辑 |

界面分成三张卡：

1. **曝光与白平衡**：曝光、色温、色调；
2. **影调**：对比度、高光、阴影、白色、黑色；
3. **色彩**：饱和度、自然饱和度。

## 4.2 操作方式

### 滑块

每条参数由 48 段轨道组成：

- **点击轨道某一段**：直接跳到该段代表的值。轨道上 25% / 50% / 75% 处有刻度线，中心有白色圆形滑块指示当前位置；
- **`−` / `+` 按钮**：按步进值微调，超出范围时夹紧在边界；
- 右侧数值实时更新。曝光保留两位小数（`+0.35`），其余参数保留整数（`+12`）；
- 已修改的参数显示为亮色，未修改显示为灰色。

> 由于轨道只有 48 段，点击得到的是该段对应的连续值，不一定正好落在步进网格上；需要精确值时请用 `−` / `+`。

### 重置

「重置」只重置当前帧的全部 10 个创意参数（`exposure` 到 `vibrance`），不会清除：

- 去闪烁修正 `deflicker`；
- 关键帧标记；
- 其他帧的调整。

### 自动关键帧

调整页右上角的「自动关键帧」默认开启。开启时，任何滑块或 ± 操作都会把当前帧标记为关键帧。关闭后，调整只作用于当前帧，不改变关键帧状态。

建议：

- 做首尾创意调色时保持开启，省去手动标记；
- 批量微调中间帧时关闭，避免生成大量关键帧导致过渡过密。

## 4.3 EV 与预览

### 总 EV

状态栏、预览顶部与调整页「序列概览」显示的 EV 是：

```text
总 EV = 曝光 exposure + 去闪烁修正 deflicker
```

- `exposure` 是你在本页设置的创意曝光；
- `deflicker` 是「视觉去闪烁」写入的逐帧修正；
- 两者相加后参与预览与最终渲染。

### 预览刷新

每次修改都会异步重新渲染当前帧的预览：

- 预览使用最长边 1400 px 的代理图，经调色后编码为 JPEG 显示；
- 连续快速修改时，旧请求会被新一代请求丢弃，界面不会回退到旧画面；
- 预览只反映当前帧，不预渲染整个序列；
- 播放时使用缓存的缩略图/预览，停止后恢复高质量预览。

### 参数如何作用

调整在渲染管线中以浮点参数保存，预览与最终渲染共享同一套色调映射：

| 参数 | 数值含义 |
|------|----------|
| 曝光 | EV，1.0 表示亮度翻倍 |
| 色温 | UI 相对单位；导出 XMP 时转换为 `5500 + 色温 × 20` 开尔文 |
| 色调 | 与 Camera Raw 的 Tint 同向 |
| 对比度 / 高光 / 阴影 / 白色 / 黑色 | 影调曲线控制点强度 |
| 饱和度 / 自然饱和度 | 色彩强度 |

> 色温不是绝对开尔文值。只有色温或色调非零时，XMP 才写 `WhiteBalance="Custom"` 并写入计算后的温度；两者都为零时写 `As Shot`。

## 4.4 XMP 映射

导出 XMP（工具页按钮或渲染时自动写入）会把当前帧参数写成 Camera Raw 兼容字段：

| 界面参数 | XMP 字段 | 备注 |
|----------|----------|------|
| 曝光 + 去闪烁 | `crs:Exposure2012` | 写入总 EV |
| 色温 | `crs:Temperature` | 仅 Custom 时写入，`5500 + 色温 × 20` |
| 色调 | `crs:Tint` | 仅 Custom 时写入 |
| 对比度 | `crs:Contrast2012` | |
| 高光 | `crs:Highlights2012` | |
| 阴影 | `crs:Shadows2012` | |
| 白色 | `crs:Whites2012` | |
| 黑色 | `crs:Blacks2012` | |
| 饱和度 | `crs:Saturation` | |
| 自然饱和度 | `crs:Vibrance` | |
| 关键帧 | `lrt:Keyframe` | `True` / `False` |
| 去闪烁 | `lrt:Deflicker` | 单独的逐帧修正 |
| 原始曝光 | `lrt:Exposure2012` | 不含去闪烁的创意曝光 |

完整字段与保留策略见 [命令行与文件格式](08-cli-and-files.md)。

## 4.5 调色工作流建议

1. **先补偿，再创作**：先运行 Holy Grail，消除拍摄过程中的曝光跳变；
2. **首尾定风格**：选首帧调整曝光、色温与影调；跳到末帧做同样的风格设定；
3. **标关键帧**：Auto 关键帧开启时，上述操作已自动标记；
4. **加中间锚点**：在光线明显变化的转折点补关键帧；
5. **应用过渡**：工具页选择平滑或线性，点击「应用自动过渡」；
6. **去闪烁**：对调色后的序列运行视觉去闪烁；
7. **检查 EV**：用曲线与状态栏确认没有异常尖峰；
8. **渲染**：渲染页选择输出规格。

> 调整只写入项目文件，不修改原始照片。删除 `.lrtassist/` 即可回到未调整状态。

## 4.6 验收清单

- 任意滑块点击后，右侧数值与状态栏 EV 同步变化；
- 「重置」后 10 个参数回到 0，但关键帧与去闪烁保持不变；
- 关闭自动关键帧后调整中间帧，关键帧数量不变；
- 切换到其他帧再切回，参数保持；
- 关闭并重新打开项目，参数与关键帧仍然存在；
- 导出 XMP 后，`crs:Exposure2012` 等于 `exposure + deflicker`。
