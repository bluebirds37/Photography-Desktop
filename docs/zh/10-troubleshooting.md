# 10. 故障排查

[English](../en/10-troubleshooting.md) · [文档首页](README.md)

本篇按现象组织，给出可能原因、诊断方法与恢复步骤。先看状态栏与 FFmpeg 胶囊，它们通常已经指出问题所在。

![FFmpeg 设置](../assets/screenshots/settings.png)

## 10.1 启动与窗口

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| macOS 双击无反应或提示未验证 | Gatekeeper 拦截未签名构建 | 「系统设置 → 隐私与安全性」允许；或本地 `cargo build --release` 后重新打包 |
| Windows 提示缺少 DLL | 发布目录不完整 | 使用完整 `dist/`，或安装 Visual C++ 运行库 |
| 窗口打开后立即关闭 | 终端启动看 stderr | 在终端运行二进制，读取 panic 信息 |
| 界面文字模糊 | 缩放比例或 GPU 驱动 | 使用系统推荐缩放；更新显卡驱动 |
| 窗口无法缩小到 1180×720 以下 | 最小尺寸限制 | 属于预期行为 |

## 10.2 导入与文件

### 打开文件夹没有反应

1. 确认参数是目录而不是文件；
2. 确认目录第一层有受支持的扩展名；
3. 查看状态栏是否有错误提示；
4. 用 `tlcore analyze <folder>` 在终端复现，错误会带上下文。

### 提示没有图像

- 目录为空；
- 只有子目录中的照片（程序不递归）；
- 扩展名不在支持列表；
- 文件被占用或权限不足。

### 某些照片显示错误

单张解码失败不会中断导入，错误记录在 `images[].error`。常见原因：

| 原因 | 处理 |
|------|------|
| RAW 格式不受 `rawler` 支持 | 回退内嵌预览；若仍失败，先导出 DNG/TIFF |
| 文件损坏 | 用其他软件验证，必要时移除该帧 |
| 色彩配置异常 | 转成 sRGB JPEG 后重试 |
| 文件正在被其他程序写入 | 等待写入完成再重新扫描 |

### 重新扫描没有更新

如果只改了 `project.json`（例如用 CLI 改了关键帧），界面仍以内存中的序列为准。请重启程序。若改了照片本身，确认文件大小或修改时间已变化；必要时删除对应缩略图。

## 10.3 预览与曲线

| 现象 | 原因 | 处理 |
|------|------|------|
| 预览空白 / 纯黑 | 解码失败或调整极端 | 看状态栏错误；点「重置」恢复默认参数 |
| 预览与最终视频亮度不同 | 预览是 1400 px 代理，最终使用全分辨率 | 以渲染结果为准；检查锐化与运动模糊 |
| 曲线没有关键帧标记 | 尚未标记关键帧 | 在预览区标记，或工具页「标记首尾关键帧」 |
| 播放卡顿 | 序列很大或磁盘慢 | 降低预览尺寸由程序自动处理；关闭其他占用磁盘的程序 |
| 修改滑块后预览延迟 | 预览异步渲染 | 属正常；连续修改只保留最后一次结果 |

## 10.4 调整与关键帧

- **滑块点击值与预期差一点**：轨道只有 48 段，点击落在段中心；用 `−` / `+` 精确调整。
- **调整后关键帧变多**：自动关键帧默认开启；在调整页右上角关闭。
- **重置后去闪烁还在**：重置只清除 10 个创意参数，去闪烁需在工具页「清除」。
- **自动过渡提示至少两个关键帧**：至少标记首尾两帧。
- **过渡后中间帧的手动调整丢失**：过渡会覆盖关键帧之间的所有值；需要保留的帧请标记为关键帧。

## 10.5 Holy Grail

| 现象 | 原因 | 处理 |
|------|------|------|
| 结果几乎没有变化 | 没有 EXIF 且亮度平稳 | 确认相机写入 EXIF；检查曲线 |
| 结果过亮 / 过暗 | 偏移或拉伸过大 | 点「重置」后重新优化 |
| 白平衡来回跳 | 灰世界代理受大面积单色影响 | 降低拉伸，或手动调整色温 |
| 自动优化很慢 | 序列很长 | 超过 600 帧会子采样；仍慢时先用较短片段试参数 |
| 应用后创意调色被覆盖 | HG 会写 exposure/temperature/tint | 先 HG 后调色；或调色后重新应用并接受覆盖 |

## 10.6 去闪烁

| 现象 | 原因 | 处理 |
|------|------|------|
| 闪烁指数没有下降 | 平滑度过小或精度过粗 | 提高平滑度，改用「标准 / 精细」，增加遍数 |
| 画面出现缓慢漂移 | 平滑度过大或精细阈值过低 | 降低平滑度，改用「标准」 |
| 恒定模式后整体变暗 | 恒定模式把全序列拉向平均值 | 关闭恒定模式 |
| 去闪烁后仍有闪烁 | 闪烁来自局部区域而非全局亮度 | 本工具只处理全局亮度；局部闪烁需其他手段 |
| 运行很久 | 多遍 + 长序列 | 先用 1 遍预览效果 |

去闪烁基于缩略图视觉曲线，不会分析全分辨率局部区域。它应在 HG 与创意调色之后运行。

## 10.7 渲染

![简化渲染设置](../assets/screenshots/render-simple.png)

### 点击开始渲染没有反应

1. 检查 FFmpeg 胶囊是否为绿色；
2. 若为红色，设置弹窗会自动打开，安装或导入 FFmpeg；
3. 检查是否有其他渲染正在运行（按钮会变为「取消渲染」）；
4. 查看状态栏是否有错误。

### 渲染失败

| 错误关键词 | 原因 | 处理 |
|------------|------|------|
| `未找到 ffmpeg` | 组件缺失或路径失效 | 设置中重新导入 / 安装 |
| `ffmpeg 失败: ...` | 编码参数或输出路径问题 | 查看 stderr；换输出目录；确认磁盘可写 |
| `No space left on device` | 中间帧占满磁盘 | 清理 `.lrtassist/render/frames/`，换输出盘 |
| `Permission denied` | 目录只读 | 换到可写目录 |
| `cancelled` / `已取消` | 用户取消 | 正常，重新渲染即可 |
| 单帧解码错误 | 某张照片损坏 | 修复或移除该帧 |

### 输出文件找不到

- 默认输出在**序列文件夹**，不是程序目录；
- 文件名包含序列名与时间戳；
- 若手动选择过输出目录，路径显示在渲染卡片顶部；
- 点击「打开位置」定位最近一次成功输出；
- macOS 上 Finder 可能滞后，稍等或手动刷新。

### 视频时长不对

时长 = 帧数 ÷ FPS。例如 180 帧 @ 25 fps = 7.2 秒。若源文件本身有重复帧，请先清理序列。

### 画面被裁切

程序使用 cover 模式适配画布，非目标比例的边缘会被裁掉。选择与素材比例一致的分辨率，或先在外部工具中统一画幅。

### ProRes 没有码率选项

ProRes 使用固定 profile 3 质量，CRF 与目标码率不生效，界面会隐藏相关控件。

### 渲染很慢

- 4K + H.265 + 高质量预设最慢；
- 运动模糊会把解码/调色次数翻倍；
- 并行度上限为 4 线程；
- 机械硬盘或网络盘会显著拖慢；
- 可先用 1080p / H.264 / 快速预设做预览。

## 10.8 FFmpeg 组件

| 现象 | 处理 |
|------|------|
| 状态一直「需要 FFmpeg」 | 安装系统 FFmpeg（如 `brew install ffmpeg`）后「导入系统」，或从压缩包安装 |
| 下载卡住 | 检查网络 / 代理；改用压缩包离线安装 |
| 导入后版本号不对 | 版本从 `ffmpeg -version` 解析；确认选择的是正确的可执行文件 |
| 切换版本无效 | 重启程序；检查 `versions.json` 与目录是否存在 |
| 卸载按钮不可用 | 正在使用该版本；先切换到系统或其他版本 |
| 组件目录不可写 | 程序会回退到用户数据目录；也可把程序移到可写位置 |

诊断：

```bash
tlcore ffmpeg-status
```

输出包含当前来源、版本、可执行文件路径、组件目录与已安装版本。若路径为空，说明没有找到可用 FFmpeg。

## 10.9 项目文件与恢复

### 项目打不开

`project.json` 解析失败通常意味着文件损坏。程序会返回错误而不覆盖原文件。处理：

1. 备份 `.lrtassist/project.json`；
2. 检查是否为合法 JSON（可用 `python -m json.tool`）；
3. 若无法修复，删除 `project.json` 后重新导入——会丢失调整与关键帧，但照片不受影响；
4. 缩略图缓存可保留，重新导入会复用。

### 误删 `.lrtassist/`

- 原始照片不受影响；
- 调整、关键帧、工作流状态丢失；
- 重新打开目录会重建项目与缩略图；
- 渲染设置恢复默认。

### 自动保存没有触发

- 程序在导入 / 渲染 / 去闪烁期间会延后保存；
- 关闭窗口会强制保存；
- 点击顶部「保存」可立即写入；
- 若保存失败，状态栏会显示错误，通常是磁盘只读或空间不足。

## 10.10 性能与资源

| 场景 | 建议 |
|------|------|
| 数千帧序列 | 导入与去闪烁会较慢；可分批处理 |
| 4K 渲染 | 预留至少 10 GB 临时空间；关闭其他大型程序 |
| 内存不足 | 减少同时运行的任务；避免在渲染时播放 |
| 网络盘 | 先复制到本地再处理 |
| 高温降频 | 渲染时注意散热；可降低预设 |

## 10.11 收集诊断信息

遇到无法定位的问题时，请准备：

1. 操作系统与版本；
2. 程序版本（窗口副标题 / 构建时间）；
3. `tlcore ffmpeg-status` 输出；
4. 复现步骤与状态栏错误文本；
5. `project.json` 中与问题相关的片段（注意可能包含本地路径）；
6. 渲染失败时 FFmpeg 的 stderr 文本。

有了这些信息，大多数问题可以在几分钟内定位。
