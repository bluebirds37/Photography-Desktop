# 算法设计

本文描述延时摄影助手的核心处理流程、数学模型和渲染参数。所有实现均在本项目内，不依赖外部图像处理软件。

## 1. 数据流

```text
照片文件夹
  ↓ 扫描 / EXIF / 缩略图
序列模型（每帧：亮度、相机曝光、调整、关键帧）
  ↓ 关键帧调色
  ↓ Holy Grail 曝光曲线
  ↓ 自动过渡
  ↓ 视觉预览 → LOESS 去闪烁
  ↓ 逐帧显影
PNG 帧 → FFmpeg → MP4 / MOV
```

## 2. 序列分析

### 2.1 EXIF 与相机曝光

从 EXIF 读取：

- `ExposureTime`：快门 `t`
- `FNumber`：光圈 `N`
- `PhotographicSensitivity`：ISO
- `ExposureBiasValue`：曝光补偿
- `DateTimeOriginal`：拍摄时间

相机曝光值（EV100）：

```text
EV = log2(N² / t) - log2(ISO / 100) + exposure_bias
```

该值用于 Holy Grail 曲线：相机曝光值的变化越大，需要补偿的曝光修正越大。

### 2.2 亮度与白平衡

缩略图在 sRGB 空间计算：

```text
L = 0.2126 R + 0.7152 G + 0.0722 B
```

对所有像素取均值得到每帧亮度 `luma`。同时计算通道均值，归一化到绿色通道：

```text
wb_r = mean(R) / mean(G)
wb_b = mean(B) / mean(G)
```

白平衡代理值：

```text
wb_proxy = log2(wb_r / wb_b) × 120
```

用于 Holy Grail 的白平衡跳变补偿。

### 2.3 视觉预览

去闪烁不直接使用相机直方图，而是：

1. 读取已缓存的缩略图；
2. 应用当前曝光、白平衡、影调调整；
3. 再次测量平均亮度。

这样去闪烁看到的是“调色后的画面”，与最终输出更接近。

## 3. LOESS 平滑

### 3.1 局部线性回归

对长度 `n` 的曲线，窗口大小：

```text
q = clamp(round(span × n), 2, n)
```

对每个样本 `i`：

1. 取包含 `i` 的 `q` 个最近样本；
2. 带宽 `d = max(x[i]-x[left], x[right]-x[i])`；
3. 对窗口内样本 `j` 计算 tricube 权重：

```text
u = |x[j] - x[i]| / d
w = (1 - u³)³
```

4. 做加权线性回归，取 `x[i]` 处的拟合值：
   
```text
slope = (Sxy - Sx·Sy/Sw) / (Sxx - Sx²/Sw)
fit[i] = (Sy - slope·Sx) / Sw
```

### 3.2 稳健重加权（可选）

通用 LOESS 支持 bisquare 重加权：

```text
m = median(|residual|)
r = |residual| / (6m)
w *= (1 - r²)²   (r < 1)
```

去闪烁使用 0 次稳健迭代，避免把真实亮度变化当作异常值压制。

### 3.3 端点与平坦曲线

- 输入为常数时直接返回常数，避免浮点噪声；
- 首尾窗口不足时自动收缩到可用样本；
- 线性输入会被局部线性回归原样保留。

## 4. 视觉去闪烁

### 4.1 对数亮度

亮度与曝光的近似关系：

```text
L ≈ L0 × 2^EV
```

因此在对数空间处理：

```text
logL[i] = log2(luma[i])
```

### 4.2 修正量

对当前调整后的亮度曲线：

1. 若“恒定模式”：目标为全局均值；
2. 否则：目标为 `LOESS(logL, span)`；
3. 修正：

```text
delta[i] = target[i] - logL[i]
```

4. 小于精度阈值时视为噪声；
5. 单次修正限制在 ±2 EV；
6. 累加到去闪烁修正，并更新曲线。

精度阈值：

```text
粗略 0.005
标准 0.002
精细 0.0005
```

换算到对数空间：

```text
eps_log = log2(1 + eps)
```

### 4.3 多遍

多遍模式重复“平滑 → 求差 → 写回”，每遍重新计算目标曲线。平滑度越小，保留的慢速亮度变化越多；平滑度越大，越接近恒定亮度。

## 5. Holy Grail 曝光曲线

### 5.1 输入

- 相机曝光值 `camera_ev`；
- 亮度 `luma`（缺失 EXIF 时的回退）；
- 白平衡代理值。

缺失值先用相邻帧线性插值；全部缺失时使用 `log2(luma)`。

### 5.2 曝光补偿

相机曝光值去均值：

```text
trend[i] = ev[i] - mean(ev)
```

创意斜坡：

```text
t = i / (n - 1)
ramp = (t - 0.5) × rotate + offset
```

曝光修正：

```text
correction[i] = -trend[i] × (1 + stretch) + ramp
```

- `stretch = 0`：完全补偿相机曝光变化；
- `stretch > 0`：过度补偿，画面随时间变暗；
- `stretch < 0`：欠补偿，保留更多原始亮度变化；
- `rotate`：线性亮度斜坡；
- `offset`：整体偏移。

随后按“初始平滑”参数做 LOESS 平滑，并限制在 ±5 EV。

### 5.3 白平衡

用白平衡代理值的高频残差补偿：

```text
slow = LOESS(wb_proxy, 0.45)
jump = wb_proxy - slow
temperature[i] = -jump × (0.35 + stretch × 0.15) + ramp × 2
```

限制在 ±100。这样可以削弱白平衡跳变，同时保留日落等慢速色温变化。

### 5.4 自动优化

搜索范围：

```text
stretch: -1.5 .. +1.5，步长 0.02（151 次）
rotate:  -4.0 .. +4.0，步长 0.04（201 次）
```

评分：

```text
score = roughness(adjusted_log_luma)
      + 0.02 × Σ|exposure|
      + 0.001 × Σ|temperature|
```

`roughness` 为二阶差分绝对值均值。长序列会先按步长降采样到约 600 点，选定参数后再应用到完整序列，避免交互卡顿。

## 6. 关键帧插值

对每一列独立处理：

- 找出关键帧索引；
- 首关键帧之前保持首值；
- 末关键帧之后保持末值；
- 两个关键帧之间：

```text
u = (i - a) / (b - a)
线性：v = va + (vb - va) × u
平滑：u' = u²(3 - 2u)
      v = va + (vb - va) × u'
```

参与插值的列：

```text
曝光、色温、色调、对比度、高光、阴影、白色、黑色、饱和度、自然饱和度
```

去闪烁修正不参与插值。

## 7. 图像显影

### 7.1 色彩空间

- sRGB → 线性：标准 sRGB 传输函数；
- 线性 → sRGB：反向传输函数，使用 4097 项查找表加速。

### 7.2 处理顺序

1. 缩放到目标尺寸（预览/缩略图）；
2. 线性 RGB；
3. 白平衡增益；
4. 曝光增益 `2^(exposure + deflicker)`；
5. 高光压缩/阴影提升；
6. 对比度、黑白场；
7. 饱和度/自然饱和度；
8. 编码回 sRGB。

白平衡增益：

```text
r_gain = 2^(temperature/100 × 0.35)
b_gain = 2^(-temperature/100 × 0.35)
g_gain = 2^(-tint/100 × 0.25)
```

### 7.3 运动模糊

渲染时对每个输出帧混合邻帧：

```text
w = 1（邻帧），2（当前帧）
out = Σ(frame × w) / Σw
```

默认 3 帧窗口，可在渲染设置中扩展。

## 8. 渲染与编码

### 8.1 并行

- 导入/视觉分析使用 2–6 线程；
- 渲染使用 2–4 线程，控制大尺寸 RAW 的内存占用；
- 帧按索引并行处理，输出连续编号的 PNG。

### 8.2 编码参数

H.264：

```text
libx264 -preset <veryfast|medium|slow>
CRF: -crf <quality>
VBR: -b:v <Mbps>M -maxrate <1.25×>M -bufsize <2×>M
-pix_fmt yuv420p -movflags +faststart
```

H.265：

```text
libx265 -preset <...>
CRF 或同样的 VBR 参数
-pix_fmt yuv420p10le -tag:v hvc1
```

ProRes：

```text
prores_ks -profile:v 3 -pix_fmt yuv422p10le
```

ProRes 不使用 CRF/码率参数。

## 9. XMP

写入标准 `crs:*`：

- 曝光、色温、色调
- 对比度、高光、阴影、白色、黑色
- 饱和度、自然饱和度
- HasSettings / HasCrop 等基础字段

去闪烁合入 `crs:Exposure2012`，便于其他支持 XMP 的软件直接读取。工作流状态写入专用命名空间，供本程序再次载入。

已有 XMP 文件采用“更新标签”而不是整文件覆盖，未识别的字段会保留。

## 10. 复杂度与限制

- LOESS 每个样本的窗口大小为 `q`，总复杂度约 `O(n·q)`；
- 去闪烁对长序列可能在秒级完成；
- HG 优化对长序列降采样后再搜索；
- 视觉预览使用 640px 缩略图，极端局部调整的亮度估计会与全分辨率有差异；
- 目标码率为 VBR 平均值，简单画面可能低于目标。
